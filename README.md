## 🛠 Developer tools & apps

- [**repokeeper**](https://github.com/vannt-dev/repokeeper) — one CLI that keeps every repository on the same standard: Conventional Commits, git hooks, CI, releases and dependency updates for 12 stacks (Node, Python, Dart, Go, Rust, Java, Kotlin, .NET, PHP, Ruby, shell/PowerShell, Dockerfiles), on GitHub and GitLab, plus code scanning, repository settings as code and optional modules for Actions cache cleanup, Dependabot auto-merge and npm/PyPI trusted publishing. `repokeeper github status` reports across all your repositories: open pull requests, Dependabot alerts, failing CI, unreleased work and a dependency graph GitHub has not re-read. [npm](https://www.npmjs.com/package/repokeeper) · [Playground](https://vannt-dev.github.io/repokeeper/)
- [**mv3-remote-code-check**](https://github.com/vannt-dev/mv3-remote-code-check) — reads a built browser extension (folder, .zip or .crx) the way the Chrome Web Store review does and fails on remotely hosted code, which Manifest V3 forbids, before the review rejects the package. CLI, GitHub Action and Vite plugin; it checks the four extensions below in their CI. [npm](https://www.npmjs.com/package/mv3-remote-code-check) · [Site](https://vannt-dev.github.io/mv3-remote-code-check/)
- [**Network Overrides**](https://github.com/vannt-dev/network-overrides-devtools) — goes beyond DevTools Local Overrides: mock API responses with a chosen status and delay (with or without calling the server), change request headers, body or URL, simulate failures and rewrite WebSocket frames. [Chrome Web Store](https://chromewebstore.google.com/detail/network-overrides-api-dev/holdjgmcnpelgclhopiejilhhkfcmpba)
- [**Markdown to PDF**](https://github.com/vannt-dev/convert-md-to-pdf) — Repeatable document builds from Markdown: a CLI for your machine or CI that writes PDF, Word, EPUB or HTML with Mermaid, LaTeX, themes, page numbers, a running header/footer, watermark and PDF bookmarks, plus a Chrome extension for PDF and HTML. [npm](https://www.npmjs.com/package/md-pdf-studio) · [Chrome Web Store](https://chromewebstore.google.com/detail/markdown-to-pdf-converter/djikikejkmkklfeklfmddaadilhahamj)
- [**Region Snap**](https://github.com/vannt-dev/region-snap) — capture an exact region of a live page as a local PNG, with text notes, numbered step marks, scrolling capture and burst shots. [Chrome Web Store](https://chromewebstore.google.com/detail/region-snap-interactive-s/gdcpiocagphfbomdokhfomjnecnjfcon) · [Site](https://vannt-dev.github.io/region-snap/)
- [**Universal File Converter**](https://github.com/vannt-dev/browser-extension) — Chrome extension that converts images, documents, PDFs, spreadsheets and structured data entirely in the browser, with PDF page tools and offline OCR to searchable PDFs. [Chrome Web Store](https://chromewebstore.google.com/detail/universal-file-converter/bekbobpfdajniiiiadbpiedlbhccidnp) · [Releases](https://github.com/vannt-dev/browser-extension/releases)
- [**Dynamic Field Kit**](https://github.com/vannt-dev/dynamic-field-kit) — schema-driven dynamic form engine for React, Vue, Angular and Svelte, with conditions written as data, labelled built-in controls and a Storybook. [Docs](https://vannt-dev.github.io/dynamic-field-kit/) · [npm](https://www.npmjs.com/package/@dynamic-field-kit/core)
